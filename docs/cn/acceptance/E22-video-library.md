# E22 Video library 「视频介绍」 (section `videos` `/v2/videos`; management = its admin-only 「管理」 tab `/v2/videos?view=manage`, section `video-management`) — acceptance standard

**Risk score:** 5 (C2 × L2 + 1: hub-global ledger rows; the only exposure is a stored media URL every member's browser fetches; media are self-hosted on the console host since `cn/r13-e`, N13-obs11) → negatives ≥ 3 (this sheet lists 12) · **Recorded build:** to fill (host `GET /api/health`) · **Status:** draft · **New module** (ported in round 12, `cn/r12-a`, N12-obs48; not in the E01–E21 video plan — this sheet is the acceptance standard for the directory that hosts the series itself)

## 1. Scope and roles
- **Routes (`backend/app/core/route_policy.py`, all `WORKSPACE_EXEMPT` = hub-global):** `GET /api/videos` = `MEMBER` (published snapshots only, `schemaVersion 3`); `GET /api/videos/manage`, `GET …/manage/{id}`, `POST /api/videos/manage`, `PUT …/manage/{id}`, `POST …/manage/{id}/publish`, `POST …/manage/{id}/unpublish`, `DELETE …/manage/{id}?expected_revision=` = `ADMIN`. Feature flag `videos` in `Settings.features` → `GET /api/capabilities.features`; without it both pages render not-found and the Demo-videos button is absent.
- **Media (round 13, `cn/r13-e` 09c72108):** nginx serves `/home/ubuntu/launchpad-media/` as `https://<console host>:<port>/media/…` (static, `autoindex off`, byte ranges, explicit MIME for `.mp4` `.webm` `.vtt` `.jpg`, `Cache-Control: public, max-age=31536000, immutable`, **no CORS** = same origin as the console). Path convention `/media/<section>/<YYYYMMDD-v2-cn-hr>/<slug>.zh-CN.mp4` (+ `.webm`, `.jpg`, `.zh-CN.vtt`). Staging a file is a deploy-ops step (`deploy.md` §8.8). The backend never uploads, proxies or probes media; the validator (`services/videos._url`) accepts a public IPv4 host with an explicit port, so `https://203.0.113.30:8443/media/...` validates (probed 2026-10-18).
- **Roles:** `demo-admin` creates / publishes / edits / withdraws entries on the 「管理」 tab of `/v2/videos` (`?view=manage`; `&edit=new` / `&edit=<id>` open the editor); `hr-intern` browses `/v2/videos`, watches, sees no 「观看」/「管理」 tabs, and gets `video-manage-forbidden` on a `?view=manage` deep link. No ownership rule: `created_by` / `updated_by` are display usernames.
- **Navigation (N15-obs14, user decision 2026-10-19):** ONE sidebar entry — 学习 → 视频介绍 (`/v2/videos`) — and the 学习 group is the LAST group, below 配置. The former 配置 → 视频管理 entry and the `/v2/video-management` page are gone; the URL redirects onto the tab (`?view=new` → `&edit=new`, `?view=edit&id=` → `&edit=<id>`).
- **Out of scope:** the recordings' content and the per-chapter case-id overlay (Q7 `render.py`); the classic console pages (retired in `cn/r13-a`, N13-obs1 — `console_version "classic"` remains a valid stored value for parity, but no CN recording uses it).

## 6. Failure classification
Ledger-only API; the media path is nginx static on the console host. ENV: the host update window (nginx reload) interrupting a playback; the NLB health check flapping. TEST: entering the instance-IP origin while recording through the NLB (NC-09 — an operator error, classify TEST and fix the URL); asserting `categories` for an area with no published video. PRODUCT: any member response carrying `revision` / `created_by` / draft `content`, any 2xx on a stale revision, any saved `http://` or private-host URL, a Demo-videos button on a module with no V2 recording.

# E04 Chat playground 「对话演练场」 (section `chat`, `/v2/chat`) — acceptance standard

**Risk score:** 11.5 (card: 3 / 4 / 4 / 0.5; DoD §4.2 lists E04 high-risk → R2 upstream 5xx + R6 long-turn interruption + R7 billable member invokes) → negatives ≥ 10 · **Recorded build:** to fill · **Status:** draft

## 1. Scope and roles
- **Routes (`route_policy.py`):** `POST /api/chat/{agent_id}`, `GET …/history`, `GET …/memory`, `GET …/sessions`, `POST …/sessions/{sid}/stop`, `GET …/sessions/{sid}/turns/{turn}/stream`, `GET /api/traces/{session_id}`, `GET/POST /api/apikeys`, `POST /api/apikeys/{id}/disable|enable`, `DELETE /api/apikeys/{id}` = `MEMBER`. Public `/v1/*` is key-authenticated (`X-Api-Key`).
- **Roles:** `demo-admin` chats with `hr-helpdesk-wb006`; `hr-intern` (member) chats and sees **only the sessions they opened** (`created_by` = their `users.id`, legacy rows by `actor_id`); an administrator lists every session (`users-and-ownership.md` §4). Reattach ownership is the turn's **sender** (`chat.turn_not_yours`), not the session's first owner. The signed-in user is the D20 policy principal. Memory actor is `<agent_id>__<username>`.
- **Out of scope:** `/v1` beyond the Inspector API tab (E14), attachments deep-dive (covered by hermetic tests only), assistant conversations (E02), isolated-workspace visibility (E19).
